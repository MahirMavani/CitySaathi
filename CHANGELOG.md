# Changelog

All notable changes to **CitySaathi** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-28

### Added
- Civic complaint management platform with automated department classification.
- Integration with Google Gemini 2.5 Flash for image defect verification.
- Interactive Leaflet geospatial mapping with Bangalore wards and defect hotspots.
- Prisma ORM data schemas with SQLite/PostgreSQL relational storage.
- Continuous Integration workflows for automated testing and schema migrations.
- MIT open source license and comprehensive developer guide.

### Fixed
- Stabilized SQLite concurrent write lockups during bulk complaint ingestion.
- Resolved routing latency between municipal department dispatch queues.
